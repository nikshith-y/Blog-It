# Blog Platform

A simple blog platform for creating, editing, and deleting blog posts. This application runs entirely in the browser and uses localStorage to persist your blog posts.

## Features

- Create new blog posts with title and content
- Edit existing blog posts
- Delete blog posts
- Responsive design that works on both desktop and mobile devices
- Automatic saving of posts to localStorage
- No server required - everything runs in your browser

## How to Use

1. Open `index.html` in your web browser
2. Click on "New Post" to create a new blog post
3. Fill in the title and content, then click "Save"
4. Your post will appear in the list of posts
5. To edit a post, click the "Edit" button on any post
6. To delete a post, click the "Delete" button on any post

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- localStorage for data persistence

## Browser Compatibility

This application works in all modern browsers that support localStorage and ES6 features:
- Chrome
- Firefox
- Safari
- Edge
